TERRAFORM ENTERPRISE

Provisioning Terraform templates

Use Terraform Enterprise to provision infrastructure from a Terraform configuration. Create a workspace, connect your configuration, set its variables, and safely review and apply the generated plan.

i

Terraform Enterprise runs Terraform remotely. Your credentials and sensitive input values remain managed in the workspace.

Before you begin

Make sure that you have an organization, permission to create workspaces, and a Terraform configuration in a supported version control repository. You also need the cloud credentials and values that your configuration expects.

  • Access to a Terraform Enterprise organization and project.
  • A Git repository containing your .tf files.
  • Cloud credentials with permission to create the requested resources.

Provision a Terraform template

Complete the following steps to provision your infrastructure with a VCS-driven workspace.

1

Create a workspace

In Terraform Enterprise, select New workspace. Choose Version control workflow, then select the organization, project, and repository that contains your Terraform template.

New workspace

◆github.com / acme / network-templateSelected
2

Configure workspace variables

Open the workspace Variables page. Add the input variables required by your configuration. Mark credentials, tokens, and other confidential values as sensitive.

name_prefix = "production"
region      = "us-east-1"
environment = "prod"
3

Review and apply the run

Queue a plan from the workspace. Terraform Enterprise retrieves the configuration, validates it, and presents the proposed changes. Review the plan, then select Confirm & Apply when it is ready to provision.

Next steps

After the apply completes, review the workspace outputs and state. Future commits to the connected repository automatically queue a new plan, giving your team a consistent, reviewable path for infrastructure changes.
